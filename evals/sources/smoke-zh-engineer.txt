## 项目经历

### 证据简历助手  
**核心开发者 | 2025-03 - 2025-07**  
项目链接：https://example.com/evidence-resume  
技术栈：TypeScript、Claude API、Node.js、React、JSON Schema  

项目简介：  
面向简历解析与优化场景的 AI 应用，支持从用户上传的简历文本中提取结构化信息，并为每个字段保留对应的原文证据，帮助用户识别“无来源陈述”“过度美化内容”和“证据不足的能力描述”。

主要职责：

- 设计并实现简历字段抽取流程，支持姓名、职位、经历、项目、教育、技能、联系方式等核心模块的结构化解析。
- 基于 Claude API 设计多阶段 Prompt，包括信息抽取、证据对齐、缺失项检测和内容改写建议。
- 为每个提取字段建立 `source_span` 与 `evidence_text`，确保 AI 生成结果可追溯到原始简历内容。
- 设计无来源陈述检测逻辑，对模型生成但原文无支撑的内容进行标记，降低“幻觉式简历优化”风险。
- 使用 JSON Schema 约束模型输出格式，提升结构化结果稳定性，减少前端解析异常。
- 构建小规模评测集，对抽取准确率、证据匹配率和无来源陈述识别效果进行持续评估。
- 参与前端交互设计，实现“原文证据高亮”“字段修改建议”“风险提示”等功能。

示例成果：

- 将简历核心字段抽取准确率从示例基线的 78% 提升至 91%。
- 将无来源陈述识别召回率提升至 86%。
- 支持 20+ 种常见简历段落格式，包括时间线式、项目式和中英混合简历。
- 形成一套可复用的“提取—校验—证据回链—评测”开发模板。

ROOM · Product Workflow

产品流程图把作品集变成一座可穿行的房子

ROOM 将简历 / 作品集网页转化为可导航的多房间 Three.js 世界。核心原则：Agent 只产出经校验的结构化数据，确定性运行时再把数据编译成稳定、可测试的 3D 世界。

契约边界：所有 agent 之间通过带版本的 JSON Schema 契约通信；任一 agent 不能直接改写另一 agent 的产物，也不能编辑渲染器。
房主（Owner）操作 系统 / Agent 自动 访客（Visitor） JSON 契约产物

03

确定性服务 · 稳定、可测试、不由 Agent 生成

docs/ARCHITECTURE.md

World Compiler

校验 world.json、解析已许可素材、构建运行时场景对象。

拒绝未验证素材进入生产

Room Runtime

房间流式加载、门过渡、相机导航、碰撞、射线拾取、HTML 覆盖层与自适应画质。

每个房间可独立加载
💬

Comment Service

评论绑定稳定语义 ID（entity_id），换主题 / 改布局也不丢失；提供审核与实时推送。

世界 / 房间 / 展品 / 回复四级
📦

Asset Registry

记录素材来源、许可、归属、哈希、面数、纹理内存、包围盒、LOD 与可用状态。

许可未知者不得进生产
